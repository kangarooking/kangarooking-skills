# 视觉提炼方法

## 1. 先找来源，再找风格

从真实照片中记录五类信息：

1. 建筑关系：转角、门洞、窗格、屋檐、墙面分割。
2. 陈列关系：货架层级、挂杆、容器、桌面、动线。
3. 产品关系：轮廓、切面、制作动作、包装开合方式。
4. 材料关系：木材、金属、玻璃、纸张、布料、陶瓷。
5. 生活关系：顾客如何停留、拿取、观看、付款和带走。

优先选择可以跨媒介复用的结构，不选择只能成为一次性插画的细节。

## 2. 创意转译公式

使用以下结构形成概念：

`真实结构 + 商业动作 + 顾客感受 = 品牌概念`

示例：

- 街角门窗 + 推门进入 + 被日常接住 = 街角打开。
- 两层货架 + 挑选商品 + 发现新鲜 = 层层发现。
- 包装折线 + 带走礼物 + 心意展开 = 打开一份心意。

不要只说“从门窗提炼 Logo”，必须说明它与购买体验的关系。

## 3. 日常高级感

优先使用：

- 真实自然光和可触摸的材料。
- 少量颜色、稳定的信息层级和有目的的留白。
- 普通店铺可实现的招牌、贴纸、纸张与陈列方式。
- 真实顾客、店员或产品，而非职业模特式摆拍。
- 具体、易懂、有生活感的短文案。

避免使用：

- 为高级而大面积黑色、金属镜面或奢侈品展台。
- 与小店生活感冲突的美术馆式抽象装置。
- 杂志封面式密集信息覆盖所有社媒物料。
- 大量粉色水彩、英文花体和传统行业模板。
- 将参考图的视觉符号直接复制到新品牌。

## 4. 参考图使用原则

将参考拆成可迁移变量：

- 摄影与平面的占比。
- 标题与主体的空间关系。
- 留白密度与信息数量。
- 色彩角色，而不是具体色值照搬。
- 材料、光线和真实程度。

每次只迁移 2 至 4 个原则。品牌概念和具体图形必须来自用户的店铺、产品或故事。

## 5. 源图保持规则

进行门店 After 时必须保持：

- 拍摄视角与空间方向。
- 主要门窗、墙面和入口比例。
- 能证明是同一家店的环境线索。
- 用户没有授权改变的建筑与产品事实。

允许改变：

- 招牌、橱窗贴、包装、价签、陈列秩序。
- 可移动家具、花架、小型灯具和软装。
- 光线整理、色彩统一和画面清洁。

若改造后无法与 Before 对应，则视为失败。
