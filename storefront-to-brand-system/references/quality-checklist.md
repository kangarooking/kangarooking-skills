# 输出质检清单

## 产品与商业

- [ ] 明确店铺卖什么、服务谁、解决什么消费需求。
- [ ] 没有虚构产地、价格、日期、地址、功效或认证。
- [ ] 物料与真实经营过程相关，而非只为展示好看。

## 创意转移

- [ ] 核心概念来自店铺、产品或购买动作。
- [ ] 能用一到两句话解释 Logo 的形态来源。
- [ ] 参考图只影响设计原则，没有复制品牌资产。
- [ ] 没有使用最常见、最廉价的行业图标作为唯一创意。

## 源图保持

- [ ] Before 与 After 能确认是同一家店或同一产品。
- [ ] 门窗、入口、主要陈列和建筑材料没有无故改变。
- [ ] 改造属于现实小店可以落地的范围。

## 设计执行

- [ ] Logo 在招牌、贴纸、价签和头像尺寸下均可识别。
- [ ] 主色、底色、辅助色角色稳定。
- [ ] 字体层级、辅助图形、纸张和摄影语言一致。
- [ ] 单张物料只有一个主要传播任务。
- [ ] 海报第一眼能看懂店铺类型和传播目的。
- [ ] 没有把开业主视觉错误做成杂志封面或抽象艺术品。

## 文字与文件

- [ ] 品牌名、标题、日期、价格、地址和营业时间准确。
- [ ] 没有乱码、伪英文、错别字或多余品牌。
- [ ] Logo 已保留单色版和可导出 SVG 的矢量版本。
- [ ] 画布保留 Logo 推导与 Before / After 过程证据。

## 最终判断

如果作品很好看但无法解释其商业用途、品牌来源或与原店的关系，不得判定为完成。
