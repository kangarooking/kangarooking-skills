# 从真实店铺到完整品牌

把“一张普通店铺照片”转化为一套有来源、有逻辑、可真实开店使用的品牌视觉。不要只生成漂亮图片；必须解释品牌从哪里来，并让同一系统覆盖空间、包装与传播。

## 输入

### 最低输入

- 至少一张真实店铺外观、店内空间或摊位照片。
- 店铺经营品类；若照片足够明确，可以先推断并向用户确认。

### 推荐输入

- 品牌名称或待命名需求。
- 产品、商品、服务或制作过程照片。
- 用户喜欢的视觉参考。
- 开业时间、地址、价格、营业时间等需要准确呈现的信息。
- 用户希望生成的物料清单。

## 输入使用

- 将真实店铺照片视为必须保留的空间锚点，而不是可随意重建的灵感图。
- 保留店铺位置、门窗比例、入口关系、主要陈列、建筑材料和可识别环境。只做用户可负担、可施工的轻改造，除非用户明确要求重建。
- 将参考图视为设计原则，不复制其中的品牌名、Logo、人物、插画、文案或独特构图。
- 需要精确呈现的品牌名、日期、价格、地址和营业时间不得自行改写或补造。
- 若只提供店铺照片，先完成可验证的分析，再建立视觉方向；不要直接套用花店、咖啡店或任何固定行业模板。

## 动态参考

- 分析空间并提炼视觉概念前，阅读 [visual-method.md](references/visual-method.md)。
- 选择与扩展物料前，阅读 [deliverables.md](references/deliverables.md)。
- 输出前必须按照 [quality-checklist.md](references/quality-checklist.md) 完成检查。

## 内部流程

### 1. 建立 Before 锚点

1. 判断输入照片是否足以识别门店类型、空间结构和主要商品。
2. 记录必须保持不变的空间特征。
3. 若没有真实照片但用户允许制作演示案例，先生成一张普通、未经品牌设计的真实店铺照片，并明确标记为 Before。
4. Before 不得提前出现完整品牌、精致招牌或网红式装修。

### 2. 诊断商业与产品

先回答以下问题，再进行设计：

- 这家店卖什么，核心消费场景是什么？
- 顾客为什么走进来，购买后会带走什么？
- 最重要的实体接触点和社媒接触点分别是什么？
- 品牌应当给人亲切、专业、年轻、自然、效率或其他哪种感受？
- 哪些事实来自用户，哪些只是视觉推断？

不得用“高级、简约、有质感”等空泛词代替分析。

### 3. 从真实结构提炼创意

1. 从门窗、转角、招牌比例、货架、包装折线、工具动作或产品轮廓中寻找 2 至 4 个可复用形态。
2. 将形态转化为一个可解释的核心概念，例如“街角打开”“层层陈列”“一口新鲜”“翻开一页”。
3. 创建简洁标志。优先采用几何关系、负形、折线或字形结构；避免直接使用行业最常见图标。
4. 标志必须在招牌、贴纸、价签和社媒头像等不同尺寸下可辨认。
5. 说明标志与真实店铺的来源关系。

### 4. 建立品牌视觉系统

至少确定：

- 标志图形与中英文组合方式。
- 1 个主色、1 个底色、最多 2 个辅助色。
- 标题字、正文字和数字信息的层级。
- 由空间结构延伸出的辅助图形或纹样。
- 摄影的光线、构图、人物状态和材料质感。

视觉系统必须适合普通消费者理解。高级感来自信息秩序、材料、留白、真实光线与一致性，不来自故作高深、大片黑色、奢侈品陈列或抽象艺术堆叠。

### 5. 先做核心验证

先生成并检查以下三项：

1. Logo 与单色版本。
2. 原店铺的 Before / After。
3. 一张品牌主视觉或开业海报。

只有三项属于同一品牌、原店仍可辨认且主视觉容易看懂，才继续扩展物料。Logo 确认后优先转为矢量对象，并保留 SVG 导出能力。

### 6. 扩展真实物料

- 根据店铺类型和顾客旅程选择物料，不机械生成固定套餐。
- 每张图只承担一个明确任务；产品组合陈列可以同框，但不要把所有物料塞进一张情绪板。
- 优先生成开店真实会用到的物料，再补展示性作品。
- 社媒主视觉必须第一眼看懂“是什么店、在传播什么”；不要默认使用杂志封面结构。

### 7. 交付过程证据

除最终物料外，至少保留以下两种过程材料：

- Logo 来源推导：真实结构 → 几何形态 → 标志。
- Before / After：同一门店或同一产品的改造对比。

它们用于证明分析和创意转移，而不是装饰案例页面。

## 输出

默认输出分为三个层级：

### A. 品牌核心

- Logo、图形标志与单色版本。
- SVG 矢量对象或可导出的矢量版本。
- 色彩、字体与辅助图形规则。

### B. 实体触点

- 品牌化店铺招牌或空间 After。
- 与行业匹配的包装、卡片、标签、贴纸、菜单或员工物料。

### C. 传播触点

- 一张社媒主视觉。
- 一组与真实经营内容相关的社媒图片，如产品日常照改造、菜单、品牌故事、位置指引或开业倒计时。

若用户指定物料，仅生成指定范围；不要擅自扩大任务。

## Ask User

仅在以下情况询问用户：

- 无法判断店铺经营品类或品牌主体。
- 品牌名、准确文案、日期、地址、价格等关键信息缺失，而生成会造成事实错误。
- 用户提供的多组参考方向互相冲突，会导致完全不同的品牌结果。
- 用户要求对真实店铺大规模改建，但预算与施工边界不明确。

其他情况先做合理假设，并清楚标记假设。

## 自检

- 原店铺是否仍可辨认？
- 品牌概念是否能从真实空间或产品中解释出来？
- Logo 是否避免了最常见的行业符号？
- 招牌、包装和社媒是否像同一个品牌？
- 每个物料是否在现实经营中有用途？
- 主视觉是否普通消费者一眼能看懂？
- 是否出现虚构事实、乱码、错误品牌名或无关装饰？
- 是否把“高级感”误做成高冷、过度留白或杂志化？
- 是否保留了 Logo 推导与 Before / After 两类过程证据？

不满足任一核心项时，先修正再扩展物料。
